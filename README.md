# Crypto Login em Python

Somos um grupo de estudantes de Sistemas de Informação e estamos desenvolvendo o **Crypto Log In**, um projeto acadêmico que tem como objetivo explorar conceitos de criptografia aplicados a um sistema de autenticação de usuários.

Além de desenvolver o sistema de login, buscamos compreender e explicar como os mecanismos de criptografia e proteção de credenciais funcionam, relacionando os conceitos estudados em sala de aula com sua aplicação prática.

## Configuração do ambiente

### Instalação do Python

Baixe e instale o Python pelo site oficial:

https://www.python.org/downloads/

Para verificar se a instalação foi concluída corretamente, execute no terminal:

```bash
python --version
```

### Criação do ambiente virtual

Dentro da pasta do projeto, execute:

```bash
python -m venv .venv
```

O ambiente virtual permite isolar as dependências utilizadas pelo projeto.

### Ativação do ambiente virtual

No Prompt de Comando (CMD), execute:

```bat
.venv\Scripts\activate.bat
```

No PowerShell, execute:

```powershell
.\.venv\Scripts\Activate.ps1
```

Caso o PowerShell bloqueie a execução do script, utilize o CMD ou execute o Python do ambiente virtual diretamente.

### Execução do projeto

Com o terminal aberto na pasta do projeto e o ambiente virtual configurado, execute:

```bash
python main.py
```
